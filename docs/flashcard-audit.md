# Flashcard audit (October 2026)

Every deck was rebuilt against its reading using a two-pass method:

1. **Section audit.** List the major concepts in each reading section, rank them
   Must know (MK) / Should know (SK) / Reference only (Ref), and name what should
   *not* become a card.
2. **Card generation.** Cards come only from MK and selected SK concepts, then the
   deck is checked as a whole for coverage, balance, staging framework over
   subdivisions, number discipline, redundancy, and Rad Onc relevance.

Card rules applied everywhere: one question = one gradable answer; no long
"list everything" answers; exact numbers only when the number defines a
treatment, cutoff, or constraint; Extra holds context that does not need to be
memorized. Card ids were kept when a card still tests the same concept (so
existing progress carries over); new concepts got new ids.
